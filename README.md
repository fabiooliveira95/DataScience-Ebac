# 🧠 Projeto de Ciência de Dados - EBAC

Este repositório contém os projetos e atividades desenvolvidas ao longo do curso de **Cientista de Dados** da [EBAC](https://ebaconline.com.br/), com foco em análise de dados, modelagem preditiva e uso prático de ferramentas do ecossistema Python.

## 🎯 Objetivo

Aplicar os conhecimentos aprendidos no curso em projetos práticos de Ciência de Dados, incluindo:
- Pré-processamento e limpeza de dados
- Análise exploratória (EDA)
- Visualização de dados
- Modelagem preditiva (Regressão)
- Avaliação de desempenho dos modelos

---

## 📁 Estrutura do Projeto

| Arquivo | Descrição |
|--------|-----------|
| `analise_exploratoria.ipynb` | Análise estatística e visual dos dados |
| `preprocessamento_dados.ipynb` | Limpeza e transformação dos dados |
| `modelo_regressao_linear.ipynb` | Construção e avaliação de modelo preditivo |
| `README.md` | Este arquivo com informações do projeto |

---

## 🧰 Tecnologias Utilizadas

- Python 3.10+

- Scikit-learn
- Jupyter Notebook
